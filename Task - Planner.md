Task-Planner.md
Purpose
This feature helps users organize and prioritize tasks using AI.

 Example Prompt
Create a weekly task plan for a project manager.

Example Output

Monday:
- Team meeting
- Review project progress

Tuesday:
- Client communication
- Update project documentation

Wednesday:
- Complete assigned tasks
- Review deadlines

Thursday:
- Team collaboration session
- Progress reporting

Friday:
- Finalize weekly deliverables
- Plan for next week

Benefits
- Improves organization
- Increases productivity
- Helps meet deadlines
